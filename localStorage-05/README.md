# Liquid Glass Quotes App

A simple React app to add, edit, and delete quotes with a  
liquid glass (glassmorphism) UI. Data is stored using localStorage.

![Preview](./preview.png)

## Features
- Add / Edit / Delete quotes
- localStorage persistence
- Glassmorphism UI

## Tech
- React
- Tailwind CSS
- localStorage

## Run
```bash
npm install
npm run dev
